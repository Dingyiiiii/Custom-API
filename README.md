# Custom-API「海关」

自用 LLM 模型中转网关项目:统合多个 LLM 上游接入点(官方 API / 中转站 / 免费额度),
对用户提供 OpenAI/Anthropic 兼容中转。无支付系统,改用配额;核心价值在「海关」双向审计层
(防用户害上游、防上游害用户)+ 价格情报/跑分自动择优路由。
